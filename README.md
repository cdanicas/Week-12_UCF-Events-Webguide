# UCF Event Planning Educational Website

An educational resource for UCF event planners providing step-by-step guidance, interactive tools, and resources for planning university events.

## Target Audience

UCF faculty, staff, and students planning events across various colleges, departments, and student organizations.

## Features

### 9 Educational Modules

1. **Conflict Management** - Check calendar conflicts with UCF events
2. **Budgeting** - Interactive budget calculator with Excel export
3. **Venues** - Browse venues across 4 UCF campuses
4. **Parking & Transportation** - Transportation planning resources
5. **Security** - Security requirements and best practices
6. **Catering Services** - Catering menu builder with Excel export
7. **Event Permits** - Permit requirements and forms
8. **Lodging** - Hotels near UCF campuses
9. **Marketing** - UCF brand standards and marketing templates

### Interactive Tools

- **Budget Calculator** - Build event budgets with visual charts and Excel export
- **Timeline Builder** - Create event timelines with milestone tracking
- **Catering Menu Builder** - Plan catering with cost estimation
- **Checklist Generator** - Generate customized event planning checklists

## Technology Stack

- HTML5/CSS3/Vanilla JavaScript
- SheetJS (xlsx.js) - Excel export functionality
- Chart.js - Data visualizations
- AOS - Scroll animations
- CSV data files for easy content management

## Development

### Installation

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Visit http://localhost:8080

### Deployment

This site is designed for GitHub Pages:

```bash
npm run deploy
```

## UCF Branding

- **Colors**: UCF Black (#000000), UCF Gold (#FFC904)
- **Typography**: Montserrat font family
- **Brand Guidelines**: https://www.ucf.edu/brand/

## Content Management

All content is stored in CSV files in the `data/` directory for easy updates without code changes.
